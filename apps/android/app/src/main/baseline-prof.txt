# An ART baseline profile: the handful of methods that must not be interpreted on a cold start.
#
# This is the other half of the cold-start fix, and on an old phone it is the bigger half. Measured on the API 35
# emulator on 2026-09-20: one software Ed25519 verification costs about 100 ms once ART's JIT has seen the loop,
# and about 4,200 ms the first time through, because a cold start runs each of these methods exactly once and the
# JIT never gets a second chance. The same is true of the JSON reader, which reads 740 KB of bundle once.
#
# A profile shipped in the APK is used by ART at install time (and by `dexopt` afterwards) to compile these methods
# ahead of time. It is supported from Android 7.0 — minSdk here — needs no dependency and no plugin, and cannot
# change behaviour: a line ART does not understand is ignored, and a method named here does exactly what it did
# before, only compiled. AGP picks this file up by name from src/main/ and rewrites it through R8's mapping for a
# release build.
#
# `H` = hot, `S` = startup, `P` = post-startup. A bare class line asks for the class to be loaded and verified.
# Keep this list short and honest: it is for code that a cold start really runs, not a wish list.
