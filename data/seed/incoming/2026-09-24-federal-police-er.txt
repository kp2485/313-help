# Police stations (safe.police) and hospital emergency rooms (health.er) in the 71 places of the widened area
# (every city and township a DDOT or SMART bus reaches, 2026-09-24).
# Leads: data/staging/federal_police.csv (USGS National Structures Dataset, 75 candidates) and
# data/staging/federal_er.csv (CMS Hospital General Information, 19 hospitals with an emergency department, placed by
# mailing city only). A candidate is only a lead: every line below was read on its OWNER's own page (the city's or
# township's police page, the sheriff's own substation page, the hospital's own emergency-room page), with WebFetch or
# a plain request that says who we are, on 2026-09-24. Web search was used only to find pages. No fact comes from a
# search snippet, a directory, Yelp, Waze, Apple Maps or the federal files themselves, except where a line carries a
# browser flag and says so. Each line's candidate is in the `# from` comment above it ("# from none" = the owner page lists
# it and the federal file does not).
#
# Wording (brief addendum, 2026-09-24):
# - A police line says "Someone is there all day and night, and there is a phone you can use." ONLY where the
#   department's own page says the lobby, the station or the department is open 24 hours (Berkley, Garden City,
#   Madison Heights, Sylvan Lake, Wixom, the Sheriff's Pontiac substation, Oakland University). Those carry
#   `Open 24/7` and flags=walk_in. Everywhere else the line says "A police station." and gives the lobby or station
#   hours the page states, or `Call first`. Office hours for administration, records or city hall are NOT used as a
#   station's hours; those lines are `Call first`.
# - An emergency room says "open all day and night" only where the hospital's own page says 24 hours / 24/7.
#   All 23 ER lines read on their pages do; the Huron Valley-Sinai line (BROWSER, unread) does not say it. No ER
#   line says free.
# - Phones are the ones the page prints for that station, labelled as the page labels them. The non-emergency numbers
#   already in data/seed/emergency.csv were reused only where the station's own page (the source_url) prints them.
#
# Notes for the steward:
# - Grosse Pointe (City): the Public Safety Department's own page gives 17320 Mack Avenue. The federal file (2020) has
#   17145 Maumee Avenue; the page does not mention Maumee. The line uses the page.
# - Oakland University Police: its own page gives the Police and Support Services Building, 201 Meadow Brook Road,
#   Rochester, MI 48309. The federal file had 2200 N. Squirrel Road (the university's main address). The line uses
#   the page. "Rochester" is the mailing city the page prints; the federal point placed it in Auburn Hills.
# - Allen Park, Grosse Pointe Farms and Sylvan Lake: the street address on the source page is the city's own address
#   in the page's header or footer (the police page does not repeat it beside the police phone). The federal file puts
#   the police station at the same address. Worth one look by a person.
# - Grosse Pointe Shores: the page prints the police numbers as "313 / 881-5500", which the page checker cannot read
#   as a phone number, so the line carries NO phone and publishes on its house number. A steward may add
#   313-881-5500 (label "Non-emergency") after reading the page.
# - Bloomfield Township: the page prints "4200 Telegraph Road P.O. Box 489 Bloomfield Township, MI 48303-0489"; that
#   ZIP belongs to the P.O. box, so the ZIP field is left empty rather than guessed.
# - Commerce Township, Orion Township and Rochester Hills (Oakland County Sheriff's substations) and the Michigan
#   State Police Metro North Post: the page gives lobby hours without days ("Lobby Hours 8am to 4pm"). They are kept
#   as written, so each line arrives call-first. Orion's page prints "Lake Orion, Michigan 48360" (mailing city).
# - Metro North Post (Oak Park) serves Royal Oak Township by contract. michigan.gov refuses scripts (403), so the
#   source is Royal Oak Township's own police page, which prints the post's address, non-emergency number and lobby
#   hours.
# - Beverly Hills and Franklin are villages inside Southfield Township; Wolverine Lake is a village inside Commerce
#   Township; Lake Orion is a village inside Orion Township. The city field is the village the page prints.
# - Chesterfield Township: the page's heading is "Records Department Open Lobby Hours"; those are the only lobby hours
#   it gives, so they are the line's schedule.
# - Henry Ford Health bought the Ascension Providence hospitals and Ascension Macomb-Oakland: the CMS names
#   ("Ascension Providence Hospital, Southfield and Novi", "Ascension Providence Rochester") are now Henry Ford
#   Providence Southfield, Henry Ford Providence Novi and Henry Ford Rochester on henryford.com. The CMS record for
#   Southfield and Novi is two emergency rooms, so it is two lines.
# - Corewell Health Trenton: the hospital's page gives 5400 Fort St.; CMS has 5450. The line uses the page.
# - McLaren Oakland's emergency page contains a hidden "Temporarily Closed" template (its closed flag is 0); the hours
#   block reads 12:00 AM - 12:00 AM every day and the text says "around-the-clock coverage". McLaren Macomb's
#   emergency page prints no phone, so its line uses the hospital's own home page (mclaren.org/macomb), which prints
#   the address, the main number and "24/7 expert care" for emergencies.
# - Garden City Hospital's emergency page lists two emergency rooms, both "Open 24 hours a day, 7 days a week, 365
#   days a year": Garden City and the new free-standing one at the Westland Community Health Center.
