# Notes for a steward:
# - assault: the app shows these with no map dot, no Save and no Directions (docs/05, docs/08). Avalon's exam sites
#   are NOT listed as places: Avalon asks survivors to call first and publishes no site addresses. Avalon's 601 Bagley
#   office is its published headquarters. Its home page still carries an old "offices are moving to 601 Bagley"
#   banner next to "officially open"; minor. Avalon's crisis line is a hotline (see convert notes): its contact page's
#   tap-to-call link dials 313-475-7233, not 313-474-7233. Never copy that link.
# - Detroit Police Victim's Assistance: the page says "24 hours, 7 days a week"; it is written as staff response, so
#   the listing says "call first" and never shows "open now" for the office.
# - money.tax: Accounting Aid Society's Summer/Fall season runs 2026-08-31 to 2026-10-16 ("Schedule Subject to
#   Change"). After import, set valid_to 2026-10-16 on each tax site's schedule rows (import:lines has no field for
#   it). Each line carries notice=Open through Oct 16, 2026. Days come from the dated calendar on the page. The
#   calendar also marks some days "Sites Close at 2pm" (9/3, 10/1) and "Sites Close at 12pm" (Mondays 9/14, 9/21,
#   9/28) without saying which site; a person should read the page and add exceptions by hand. The Fisher site is
#   "FCC East" in the list and "FREC East" in the calendar; the line uses the school name. The Jan-Apr 2027 season
#   must be re-researched in January 2027.
# - money.tax income limit ($69,000) is from Accounting Aid Society's main page, modified 2026-02-27.
# - money.benefits: MDHHS office facts are from the office iframe page (mdhhs.michigan.gov/CompositeDirPub/...),
#   which is the page that prints the address and information line as plain text. Office hours are not printed.
#   The ZIPs each office serves come from MDHHS's "Wayne County District Offices Zip Code Assignments" PDF, dated
#   October 8, 2025. Greenfield/Joy: that PDF prints ZIP 48236 for the office itself, the office page prints 48228;
#   the line uses the office page.
# - Detroit Area Agency on Aging: MI Options is the new name for MMAP. Service area is from DAAA's /areas-we-serve/.
