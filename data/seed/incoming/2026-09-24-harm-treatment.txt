# and Macomb counties outside Detroit, Hamtramck, Highland Park and Dearborn). Categories: harm.narcan, harm.supplies,
# treatment.crisis, .detox, .residential, .outpatient, .meds, .recovery.
# Method: read on each organization's own site (or its county's own site or map data) with a plain request that says
# who we are, on 2026-09-24; search was used only to find sites. SAMHSA's National Directory, its OTP list and
# findtreatment.gov were used only to find candidates and their websites, never as the source of a fact on a line.
# Every line's source_url was fetched and run through pipeline/src/page-match.ts on 2026-09-24: all match (phone and
# street number on the page) except the two Sacred Heart lines, flagged BROWSER below.
# Wayne County's 77 Well Wayne stations are already ingested (data/ingested/wayne_well_wayne_stations.csv), so there are
# no Wayne harm.narcan / harm.supplies lines here.
# Wording: no line says "free" unless the owner's page says so; "medicaid" only where the page says Medicaid.
#
# Notes for a steward:
# - Oakland County's own "Narcan Locations" map (Access Oakland; FeatureServer
#   services1.arcgis.com/GE4Idg9FL97XBa3P/.../Narcan_Locations/FeatureServer/0, 153 points, last edited 2026-08) is the
#   county's own data. Only the 10 vending machines and cabinets run by the Health Division or Community Corrections
#   are lines here, with the layer's JSON as source_url (one entry per place, read like the Gleaners data file). The
#   other 143 are "Save a Life" boxes kept by the Alliance of Coalitions for Healthy Communities (and one by FAN).
#   Those belong in data/sources.yaml as an ingested layer like wayne_well_wayne_stations, not as hand lines; if that
#   layer is added, drop these 10 lines in favour of it. Data errors seen in the layer: 27725 Greenfield Rd is filed
#   as Pontiac with ZIP 48076 (it is Southfield; the line says Southfield), one city is "Hazel Pak", and some points
#   are outside Oakland (Southgate, Taylor, Canton, Flint). The layer gives no hours, so these lines say so.
# - Harm reduction clinic, Pontiac: the page is the County's "harm-reduction-syringe-services" page. It does not list
#   the supplies in words, so the line does not either. It also says: mobile outreach Wednesday afternoons in Ferndale
#   and Hazel Park (no address; not a line).
# - Henry Ford Macomb Narcan machine: the machine is described on Henry Ford's own news page
#   (henryford.com/news/2026/05/free-naloxone-now-available-through-vending-machine-at-henry-ford-macomb-hospital),
#   "front entrance of the Emergency Department for 24/7 access". That page has no address, so source_url is the
#   hospital's location page. Their ER itself may arrive as health.er from another batch; this is a different thing.
# - Families Against Narcotics: the site is faceaddictionnow.org. The outreach line has no address on purpose (they come
#   to you). The peer line's number is 833-202-HOPE, printed as digits only on the contact page (source_url); "free"
#   is from faceaddictionnow.org/programs/peer-recovery-coaching.
# - Live Rite: the page still carries an old COVID notice about hours, so the line says call first. MCCMH names Live Rite
#   and CARE's center as Macomb's recovery centers (mccmh.net/substance-use-disorder/).
# - Sober Support Unit: OCHN's treatment page gives the address and "Hours: Mon-Fri 8:00 AM - 8:00 PM"; OCHN's
#   recovery page says it is open 24/7, 365 days, no appointment. Common Ground's locations page no longer lists the
#   Resource & Crisis Center. The owner pages disagree, so the line says call first: a person should call 248-464-6363
#   and confirm the unit is still at Building 32E before this is published.
# - Substance Use Engagement Center (MCCMH): 24/7, but reached by screening through the crisis line; MCCMH publishes no
#   address, so the line has none.
# - Meridian: office hours are business hours; the programs run day and night, so the hours stay as text.
# - Maplegrove: private insurance; its page says it does not take Medicaid or Medicare for live-in treatment. Kept so
#   the eligibility sentence can steer people; drop it if the app should list only publicly funded treatment.
# - Henry Ford Eastwood: only the Clinton Township and Livonia clinics list "Addiction Medicine" among their services;
#   the St. Clair Shores and Southfield (Greenfield Ste 445) clinics mention substance use only as a condition, so they
#   are left out. Eastwood Recovery Center's page does not name a level of care; it is filed as outpatient.
# - Quality Behavioral Health: the locations page prints 586-480-1438 and 866-287-5710 for each outpatient/MAT site with
#   no labels; phone2 is labelled only as the second number. SAMHSA's OTP list shows Sterling Heights and Troy as
#   methadone programs.
# - Therapeutics LLC: the site's page title is a leftover template name, but its clinic list is specific. SAMHSA lists
#   Pontiac with 248-525-6832; the owner prints 248-977-3758 for Pontiac, which the line uses.
# - Bio Med: the owner prints 31851 Gratiot Ave; SAMHSA prints 31581. The line uses the owner's number. A person may
#   want to confirm by phone.
# - Team Wellness Southgate: two unlabeled numbers (734-324-8326, 734-324-8327); the line uses the first. The substance
#   use page lists all clinics without saying which offer it.
# - Easterseals MORC: the substance use page names no office, so the line uses the Auburn Hills headquarters printed on
#   that page. SAMHSA lists Center Line, Walled Lake and Southfield (9 Mile) as their treatment sites; not listed here.
# - ACC Troy and Sterling Heights: the directory calls both "mental health services"; the behavioral health page lists
#   "substance abuse & co-occurring treatment" among the department's services.
# - Clinton Counseling Center: site footer (c) 2014; SAMHSA still lists the site. Call before first publish.
