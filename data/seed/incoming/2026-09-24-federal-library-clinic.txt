# Federal-candidate check, batch "federal-library-clinic", written 2026-09-24: public library buildings (rec.library) and
# HRSA health-center sites (health.clinic) in the 71 places added on 2026-09-24, starting from the staged leads in
# data/staging/federal_library.csv (IMLS Public Libraries Survey FY 2024, 73 outlets) and
# data/staging/federal_clinic.csv (HRSA health-center sites, 37). A federal row is only a lead: no fact below comes from
# either file. Method: every line was read on the owner's own site (the library's site, or its page on its own city's
# official site; the health center's own site) on 2026-09-24, one page at a time, with the pipeline's own honest user agent
# (pipeline/src/page-match.ts fetchPage); each line's phone and street number were then checked on its source_url with the
# same matcher `pnpm check:sources` uses (listingOnPage). Web search was used only to find sites. Where a site refused
# scripts, WebFetch was tried; those lines are marked BROWSER.
#
# Notes for the steward:
# - Library `what`: every row says "A public library ... Borrow books with a library card." It says computers, Wi-Fi or
#   internet only where the library's own site names that service (a menu item such as "Public Computers & WiFi" counts;
#   "Wireless Printing" alone does not). "Free" appears only where the page says free (Riverview, Hazel Park, Berkley Wi-Fi).
# - Seasonal hours: where a page gives school-year hours and different summer hours, the schedule is the current
#   (September) one and a `notice` says which days change in summer, or a comment above the line does.
# - Several federal phones and addresses are out of date; each line uses what the owner's page prints, and the comment
#   above it says so (Livonia, Baldwin, Rochester Hills, Clinton-Macomb, Fraser, Commerce ZIP).
# - health.clinic: 24 of the 37 HRSA sites are already lines in 2026-09-24-health.txt (Honor Community Health, MyCare,
#   Wellness Plan, Western Wayne, Wayne County Healthy Communities); they are not repeated
#   here. Only three new lines: Advantage Health's two Warren offices (the org's real site is ahcdetroit.org; its
#   medical-services page lists both Warren addresses beside the one phone, and is the page the two Detroit Advantage rows
#   already use) and MyCare's behavioral health office in Center Line.
# - Advantage Health's page gives one set of hours for the whole organization (Mon, Tue, Thu, Fri 8am-5pm; Wed 10am-7pm)
#   without tying it to a site; the Detroit rows are call-first, so these two are too.
#
