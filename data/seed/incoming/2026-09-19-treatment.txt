# Drug and alcohol treatment places in Detroit and Highland Park: detox, live-in treatment, outpatient treatment and
# medicine for opioid use disorder. (No harm.supplies or treatment.crisis lines: see notes below.)
# Research notes: docs/research/2026-09-19-new-help/treatment-1-places.md and treatment-2-system-and-data.md.
# Pages read 2026-09-19 with a plain request that says who we are. Every fact on a line comes from that provider's
# own page (the source_url column). Aggregators were used only to find names. SAMHSA's OTP list and DWIHN's
# provider directory CSV ("Last Updated 04/06/2026") were used only as cross-checks that a place is still running,
# never as the source of a fact on a line.
# Notes for a steward:
# - Wording: no line says treatment is free. DWIHN's rule for uninsured callers needs one call to confirm
#   (treatment-2 notes, section 1). Elmhurst's own page says no one is turned away for inability to pay, so its two
#   lines say that.
# - Never copy a DWIHN number from a provider page. Several print a wrong one (listed in the convert notes). Lines
#   that say "call DWIHN's access line" rely on the DWIHN number the app already shows (emg_dwihn_crisis).
# - Salvation Army Harbor Light: the source page's path says "monroe" but it is the whole Harbor Light system page and
#   lists the Detroit campus first. Its history text still sends women outside Detroit to "SEMCA"; that is stale, do
#   not copy it. Cost is not stated on the page.
# - QBH East Grand Blvd and Medbury: the page prints two unlabeled numbers for each site (313-922-2222 and
#   313-922-3333). The line uses 313-922-2222, which DWIHN's list also shows; phone2 is QBH's "24/7 central intake".
#   Medbury is listed under medicine because SAMHSA's OTP list and DWIHN's list show it as a methadone clinic; QBH's
#   page lists it under detox and live-in treatment. Cost is not stated on QBH's pages.
# - Sobriety House: its own site was last changed in 2024. DWIHN's April 2026 list still shows the same address and
#   phone. A person should call before first publish. Its footer prints a wrong DWIHN number; never copy it.
# - Mariners Inn: site footer is (c) 2024; DWIHN's April 2026 list still shows 445 Ledyard with the same phone. Call
#   before first publish.
# - CLASS Agency: footer (c) 2022. The Detroit Health Department's 2026 Behavioral Health page lists it as a partner,
#   and DWIHN's 2026 list shows it (as prevention). A person should confirm outpatient treatment is still offered.
# - New Light: hours are clinic and dosing hours. New-patient intake hours are not published, so the line says to
#   call first.
# - Detroit Recovery Project Eastside: hours are not on the owner page (only the outreach desk's hours are).
# - No harm.supplies lines: no syringe service program's own page names syringe services in text we could read
#   (CHAG, DRP, ECHO, Safe Point, CHASS, UNIFIED are held). The Wayne County "Well Wayne" naloxone station map is a
#   data-source question for Kyle, not lines.
# - No treatment.crisis lines: the DWIHN Care Center is already listed (sal_dwihn_care_center); Team Wellness East
#   and the ECHO Engagement Center are held.
# - Recovery homes are link-out only (MARR's certified list), never lines.
