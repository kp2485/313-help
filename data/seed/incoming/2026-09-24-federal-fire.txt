# Fire stations in the 71 places added on 2026-09-24 (every city and township a DDOT or SMART bus reaches, outside
# Detroit, Hamtramck, Highland Park and Dearborn). Batch "federal-fire", written 2026-09-24.
# Candidates: data/staging/federal_fire.csv (157 rows from USGS The National Map, National Structures Dataset, Fire
# Stations/EMS Stations). A candidate is only a lead: every line below was found on its OWNER's page (the city's or
# township's fire or public-safety page, or the department's own site) and written from that page alone.
# Method: read on each department's own site on 2026-09-24, one page at a time, fetched with an honest user agent
# ("313help-research (open-source civic directory)"). Wixom's and Shelby Township's pages refused that fetcher and were
# read in a browser; gpwmi.us (Grosse Pointe Woods) closed the connection on it and was read with curl's own default
# agent. Lines the source check still cannot confirm are marked BROWSER (Grosse Pointe Woods, Shelby Stations 2-5).
# Web search was used only to find the pages; no fact comes from a search snippet, a directory, a map app or the
# federal dataset (except a few ZIP codes where the owner's page prints none - noted per line).
# 139 lines: 135 of the 157 candidates plus 4 stations the dataset missed or had at an old address ("# NEW").
# Each line's phone and street number were then checked on its source_url with the same matcher `pnpm check:sources`
# uses (pipeline/src/page-match.ts fetchPage + listingOnPage).
#
# Wording (brief addendum):
# - "Firefighters are there all day and night, but they go out on calls." + "Open 24/7" ONLY where the owner's page
#   says the stations are staffed around the clock (24 hours / career or full-time staff on every shift). The quote
#   is in the comment above the line.
# - Otherwise "It is not always staffed. In an emergency, call 911." + "Call first". For several career departments
#   (e.g. Dearborn Heights, Redford, Southgate, Inkster) this is only because their page never says it; a steward
#   who confirms round-the-clock staffing can upgrade those rows.
# - Public-safety departments (one officer does police and fire) are named "public safety station"; the building
#   may also appear in the police batch.
# - A station whose page prints no phone has no phone (the house number is on the page). Where the page prints only
#   a department-wide number, it is labelled as such ("Fire department main line").
#
# NOT listed (reasons in the batch report): River Rouge, Grosse Pointe Farms, Walled Lake, Mount Clemens (no station
# address tied to the station on any owner page); Commerce Township (owner page names only its headquarters, not
# its stations); White Lake Township (no station addresses on the owner's pages); Rochester Hills Stations 2-5,
# Westland Stations 3-5 (no address on an owner page); Roseville headquarters (under renovation per the City);
# Waterford Station 10 in Pontiac (not on the owner's list: "1 unmanned station ... used by the Pontiac DPW");
# West Bloomfield Station 9 (Orchard Lake Village, outside the area); outdated dataset addresses replaced by the
# owner's (Westland Station 2, Shelby Township Station 4, Warren Station 5, Grosse Pointe City).
