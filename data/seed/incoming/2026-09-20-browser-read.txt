# Notes, line by line:
# - The four DMC emergency rooms: DMC publishes a separate "- Emergency" location page for each ER, and each
#   one prints "Monday: Open 24 hrs ... Sunday: Open 24 hrs". The plain hospital pages for Detroit Receiving
#   and Harper print only visiting hours (8 a.m. to 8 p.m.), so the ER pages are the source_url. DMC Hutzel
#   Women's Hospital shares Harper's address and phone but is NOT tagged Emergency in DMC's own location
#   list, so there is no Hutzel line: Harper is the ER at 3990 John R.
# - Children's Hospital of Michigan ER prints its phone only as "(313) 745-KIDS". We do not publish a number
#   a page does not print in digits, so that line carries the address and no phone. A steward can add the
#   digits after one call.
# - John D. Dingell VA: va.gov draws its numbers with a <va-telephone> element, so no number is visible as
#   text. The numbers below are the ones the VA's own page carries in that element (contact="3135764436",
#   "3135764437", "3135761000"). Because they are not plain text, no automatic check can ever confirm them:
#   a steward should confirm by phone before this goes live.
# - Concentra is occupational health first. It is listed only because its own page labels the centre
#   "WALK-IN CLINIC" and lists "Urgent Care" among services provided. If a steward would rather not list an
#   employer-health clinic at all, drop this line.
# - Wayne County Clerk: the held row's 400 Monroe Street, Suite 605 is CONFIRMED by the Clerk's own page. The
#   "640 Temple Street, Suite 625" hint was wrong. The Clerk's own phone is (313) 967-6938, not the
#   313-224-0270 we had from the City's page. In-person is appointment only and the counter closes for lunch,
#   so the hours are kept as written and the row says call first. The page states no fee waiver of any kind.
# - CEO Detroit: the page says the programme is "exclusively to people recently released from incarceration"
#   and the model page says participants are paid at the end of every shift. Neither page says whether a
#   person may walk in or must be referred, so the line does not claim either.

#   centre's own address and phone and says call first. "No out-of-pocket costs for doctor visits, lab work,
#   or medications" is the page's own sentence, which is why it is health.clinic.
